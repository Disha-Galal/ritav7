# هذا المشروع بواسطة Gogo & Disha ®

Foxy / Rita V2.1

الغرض
-------
مستودع تطوير لـ ritav2.py، وهي أداة سطر أوامر بلغة Python لتقييم المصادقة. تتضمن الأداة تحليل النماذج، وعمليات فحص مصادقة قابلة للتهيئة، وتكامل اختياري مع DeepSeek، ومخرجات محلية بصيغة SQLite/جلسة. استخدم الأداة فقط مع الأنظمة والحسابات التي لديك صلاحية لتقييمها.

محتويات المستودع
-------------------
foxy/
    ritav2.py
    Readme.txt
    requirements.txt

هذه هي الملفات الثلاثة الوحيدة المخصصة للتحكم في الإصدار. يجب أن تبقى قواعد البيانات المحلية، وقوائم بيانات الاعتماد، وقوائم الأهداف، وملفات المتصفح/الجلسة، وذاكرات التخزين المؤقت، والبيئات، والسجلات خارج عمليات الالتزام (commits). لا يتم تضمين أي قوائم بيانات اعتماد.

الإعداد
-----
استخدم Python 3.10 أو أحدث مع venv و pip. في Ubuntu (بما في ذلك Ubuntu داخل Android PRoot)، قم بتثبيت python3 و python3-venv و python3-pip باستخدام apt إذا لزم الأمر.
قم بتشغيل هذه الأوامر في دليل المستودع:

    python3 -m venv /tmp/foxy-venv
    . /tmp/foxy-venv/bin/activate
    python -m pip install -r requirements.txt
    python ritav2.py --help

يخرج أمر المساعدة قبل إنشاء قاعدة بيانات أو إجراء طلبات مستهدفة. يسرد ملف requirements.txt التبعيات المباشرة دون تثبيت إصدارات محددة؛ إنه ليس ملف قفل (lockfile). مكتبة tqdm مطلوبة عند وقت الاستيراد. توفر مكتبة requests عميل HTTP احتياطي؛ بينما تدعم مكتبات curl-cffi و cryptography و Playwright مسارات كود اختيارية.

للحصول على وظائف تعتمد على المتصفح، قم بتوفير Playwright Firefox بشكل منفصل:

    python -m playwright install firefox

يحتاج Firefox أيضًا إلى مكتبات نظام تشغيل متوافقة. قد تتطلب بيئة Android Termux الأصلية و PRoot تكوينًا إضافيًا للمتصفح/الشاشة؛ لم يتم التحقق من تشغيل المتصفح كجزء من هذا الرفع. يقوم البرنامج النصي افتراضيًا بتعيين DISPLAY إلى :0 عند عدم ضبطه، وتتطلب العملية التي تظهر واجهة المستخدم خادم عرض يعمل.

في بيئة Android/Python 3.14 الأصلية المستخدمة للتحضير، فشل تثبيت التبعية الكاملة أثناء بناء أدوات Rust الخاصة بـ cryptography. لـ
مراجعة المصدر وأمر المساعدة، تكفي بيئة عمل بسيطة:

    python -m pip install tqdm requests
    python ritav2.py --help

استخدم بيئة Ubuntu متوافقة لتثبيت كافة التبعيات؛
تتطلب مسارات المتصفح والتشفير الاختيارية تحقُّقًا منفصلًا.

الإعدادات والأسرار
-------------------------
DEEPSEEK_API_KEY: بيانات اعتماد API اختيارية تُقرأ من بيئة التشغيل. في حال عدم وجود مفتاح،
تتوقف مساعدات الذكاء الاصطناعي عن العمل دون الاتصال بـ DeepSeek. خيار --ai-key الحالي
مدعوم أيضًا؛ يُفضل حقن المفتاح عبر بيئة التشغيل لتجنب ظهوره في سجل الصدفة (shell history) أو قائمة العمليات. ترسل وظائف الذكاء الاصطناعي نصوص HTML/السياق أو مقتطفات الرد إلى DeepSeek، لذا قم بتفعيلها فقط عند السماح بهذا النقل.

RITA_DECODE_SECRET: سر اختياري يُستخدم لاشتقاق مفتاح Fernet لمسار فك تشفير كلمة المرور الحالي. تمت إزالة سر الاشتقاق المضمن في الكود لهذا الإصدار. إذا كان هذا المتغير مفقودًا، يتم تخطي عملية فك التشفير. تتطلب البيانات المشفرة سابقًا توفير سرها الأصلي بشكل خاص. تظل معلمات الملح (salt) الثابتة واشتقاق المفاتيح تفاصيل تنفيذ قديمة، وليست تصميم تشفير موصى به. لا تضع قيمًا حقيقية في المصدر أو التوثيق أو عمليات الالتزام (commits).

لا يقوم البرنامج بتحميل ملفات .env تلقائيًا. قم بتوفير المتغيرات من خلال بيئة التشغيل أو مخزن أسرار الوكيل الخاص بك. لا يلزم وجود مفتاح API لقراءة المصدر أو تثبيت التبعيات أو عرض المساعدة.

بيانات وقت التشغيل
------------
يمكن للبرنامج إنشاء ملفات bruteforce1.db و rita_session_*.pkl في دليل العمل الحالي.
قد تحتوي هذه الملفات على كلمات مرور، ملفات تعريف ارتباط (cookies)، رموز (tokens)، وبيانات استجابة. حافظ على سرية بيانات وقت التشغيل واجعلها خارج Git. لا يتم تشفير سجلات SQLite وملفات pickle بواسطة هذا البرنامج. قم بتشغيل التقييمات من دليل عمل خاص ومنفصل. لا تقم أبدًا بتحميل ملفات pickle من مصادر غير موثوقة.
